mscorefonts RPM repository

Install the repository on Fedora, RHEL, CentOS, Rocky Linux, or AlmaLinux by creating /etc/yum.repos.d/mscorefonts.repo with:

[mscorefonts]
name=mscorefonts
baseurl=https://nvanlaerebeke.github.io/mscorefonts2/RPMS/
enabled=1
gpgcheck=1
repo_gpgcheck=1
gpgkey=https://nvanlaerebeke.github.io/mscorefonts2/RPM-GPG-KEY-mscorefonts.asc

Then refresh the repository metadata and install the package:

sudo dnf clean metadata
sudo dnf makecache
sudo dnf install msttcore-fonts-installer

Browse the repository files in RPMS/, or view the repository metadata.
